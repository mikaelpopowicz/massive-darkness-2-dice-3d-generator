# Final 3MF Files

Use these files in Bambu Studio.

- `all_dice.3mf`: all dice in one file.
- `individual/`: one file per die color.

These are tuned for a Bambu P2S with a 0.4 mm nozzle and 0.12 mm High Quality profile.
Symbols have 0.2 mm visible relief and 0.6 mm total thickness.
The black die red symbols use a -0.03 mm buffer to preserve black gaps between claw marks.
Each individual die file contains only two material colors: die body and symbols.
